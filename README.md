# Прибыль на Ozon — установка на VPS

Сайт с двумя режимами:

- **Файл.** Продавец перетаскивает отчёт о начислениях и файл «Товары и цены». Всё считается в его браузере, на сервер ничего не уходит.
- **API.** Продавец вставляет Client-Id и API-ключ «только на чтение». Сервер проверяет ключ в Ozon, хранит его в зашифрованном виде и выдаёт личную ссылку `/d/…` на дашборд. Данные обновляются сами: при открытии, если прошло больше 6 часов, и по кнопке «Обновить».

Внутри два контейнера: `app` (Python, FastAPI) и `caddy` (веб-сервер, сам получает и продлевает HTTPS-сертификат).

## Что нужно

1. **VPS** с Ubuntu 22.04 или 24.04. Хватит 1 ядра и 1 ГБ памяти. Сервер лучше брать в России: на нём хранятся данные продавцов (закон 152-ФЗ).
2. **Домен**, например `profit.example.ru`. В DNS у регистратора создайте A-запись на IP вашего VPS. Подождите, пока запись начнёт работать: `ping profit.example.ru` должен показывать IP сервера.

## Установка

Все команды выполняются на VPS. Подключитесь к нему: `ssh root@IP_СЕРВЕРА`.

**1. Установите Docker**

```bash
curl -fsSL https://get.docker.com | sh
apt install -y unzip
```

**2. Загрузите проект.** На своём компьютере, в папке с архивом:

```bash
scp ozon-profit.zip root@IP_СЕРВЕРА:/opt/
```

Затем на VPS:

```bash
cd /opt && unzip ozon-profit.zip && cd ozon-profit
```

**3. Настройте**

```bash
cp .env.example .env
docker run --rm python:3.12-slim python -c "import base64,os;print(base64.urlsafe_b64encode(os.urandom(32)).decode())"
nano .env
```

Вторая команда выведет строку — это ключ шифрования. В `.env` заполните:

- `DOMAIN` — ваш домен;
- `TG_USERNAME` — ник в Telegram без @, он появится в подписи внизу страницы;
- `FERNET_KEY` — строка из команды выше.

Сохраните: Ctrl+O, Enter, Ctrl+X.

> Сохраните `FERNET_KEY` в надёжном месте. Без него сохранённые ключи клиентов не расшифровать, и всем придётся подключаться заново.

**4. Откройте порты и запустите**

```bash
ufw allow 22 && ufw allow 80 && ufw allow 443 && ufw --force enable
docker compose up -d --build
```

Через минуту откройте `https://ваш-домен`. Если страница не открывается, посмотрите журнал: `docker compose logs -f` (выход — Ctrl+C). Чаще всего домен ещё не указывает на сервер, и Caddy не может получить сертификат.

## Первая проверка на своём кабинете

Код для API проверен на тестовых данных в формате официальной документации Ozon. На настоящем кабинете он ещё не запускался. Поэтому первым подключите свой кабинет:

1. В кабинете Ozon откройте Настройки → API ключи, нажмите «Сгенерировать ключ» и выберите одну роль — **Admin read only** (не полный Admin). Ключ показывается один раз, Client-Id указан на той же странице.
2. На сайте внизу страницы вставьте Client-Id и ключ, нажмите «Подключить».
3. Сравните «Ozon перечислит» за полный месяц с итогом в «Детализации начислений» за тот же месяц.

Если цифры не сходятся или появилась ошибка, пришлите мне текст ошибки и журнал (`docker compose logs app --tail 100`).

## Как делиться сервисом

Клиентам отправляйте только главный адрес сайта, например `https://seller-profit.online/`. Каждый, кто подключает кабинет, получает свою отдельную ссылку `/d/…`, и чужих данных не видит.

**Не отправляйте никому свою личную ссылку `/d/…`**, которую вы получили после подключения своего кабинета. Кто откроет эту ссылку, тот увидит ваши данные, так что храните её как пароль. Если она случайно ушла не туда, нажмите на дашборде «Отключить» или удалите ключ в кабинете Ozon.

## Обновление

Сайт обновляется сам из GitHub. Один раз включите автообновление:

```bash
cd /opt/ozon-profit && git pull && sh deploy/install-autoupdate.sh
```

После этого сервер каждые 2 минуты проверяет ветку `main` и, если там новые коммиты, забирает их и пересобирает сайт. `.env` и данные не трогаются. Журнал обновлений: `tail -f /var/log/ozon-profit-update.log`.

Обновить вручную, не дожидаясь: `sh /opt/ozon-profit/deploy/autoupdate.sh`. Выключить: `rm /etc/cron.d/ozon-profit-update`.

## Резервная копия

```bash
cd /opt/ozon-profit
docker run --rm -v ozon-profit_appdata:/data -v "$PWD":/backup alpine tar czf /backup/backup-$(date +%F).tgz /data
```

Копия бесполезна без `FERNET_KEY` из `.env`: храните их вместе, но не в открытом доступе.

## Если Ozon поменял API

Ozon периодически выпускает новые версии методов и отключает старые. Адреса методов собраны в начале файла `app/ozon.py`:

| Что | Метод |
|---|---|
| Финансовые операции | `/v3/finance/transaction/list` |
| Список товаров | `/v3/product/list` |
| Информация о товарах (название, SKU) | `/v3/product/info/list` |
| Цены и себестоимость | `/v5/product/info/prices` |

Если в журнале появится ошибка 404 по одному из них, сверьтесь с актуальной документацией на docs.ozon.ru/api/seller и поменяйте путь.

## Перед публичным запуском

- Добавьте на сайт политику обработки персональных данных и пользовательское соглашение: сервис хранит ключи и данные продавцов.
- Чтобы закрыть подключение по API, удалите форму в `app/static/index.html` (блок `id="api"`). Режим «Файл» продолжит работать.
