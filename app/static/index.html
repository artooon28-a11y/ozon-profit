Сколько вы на самом деле зарабатываете на Ozon

В кабинете Ozon видно выручку и десятки строк начислений, но не чистую прибыль. Здесь за минуту видно, сколько осталось с каждого товара после комиссии, логистики, невыкупов, налога и себестоимости. Выберите удобный способ ниже.

  • Из чего на самом деле состоят расходы Ozon — по каждому заказу.
  • Сколько вы теряете на невыкупах и возвратах.
  • Какие товары приносят деньги, а какие работают в ноль.

Где взять отчёт

  4. Перетащите оба файла в поле выше.

Подключить кабинет по API

Один раз вставьте ключ — и данные будут подтягиваться сами, без скачивания файлов. Дашборд откроется по личной ссылке.

Обновляется самСебестоимость из OzonКлюч только на чтение

Как получить ключ (1 минута)
  1. В кабинете Ozon откройте Настройки → API ключи (раздел Seller API) и нажмите «Сгенерировать ключ».
  2. Введите любое название, например «seller-profit», выберите одну роль — Admin read only — и нажмите «Сгенерировать». Другие роли не отмечайте, а полный Admin не выбирайте.
  3. Сразу скопируйте ключ: Ozon показывает его один раз. Client-Id указан на той же странице над списком ключей.
  4. Вставьте Client-Id и ключ ниже. Вы получите личную ссылку на свой дашборд — не пересылайте её никому: кто её откроет, увидит ваши данные.
Ключ Admin read only позволяет только читать данные: изменить цены, товары или заказы им нельзя. Он хранится на сервере в зашифрованном виде. Чтобы отключиться, удалите ключ в кабинете Ozon — доступ пропадёт сразу. Не присылайте ключ в переписке.

Как посчитать чистую прибыль на Ozon

Почему в кабинете Ozon не видно реальной прибыли

Кабинет показывает выручку и начисления: комиссию, логистику, обработку отправлений, эквайринг, обратную логистику, штрафы. Каждое начисление — отдельная строка, часть из них приходит через несколько дней после продажи. Себестоимость и налог Ozon не учитывает вовсе, поэтому сумма к выплате ещё не прибыль.

Что входит в расчёт

Чистая прибыль = цена продажи − комиссия Ozon − логистика − обратная логистика невыкупов − услуги приёма и доставки − эквайринг − штрафы − налог − себестоимость. Калькулятор собирает все строки отчёта по каждому заказу и раскладывает их по товарам.

Что такое прибыль с учётом выкупа

Каждый невыкуп стоит вам логистики туда и обратно, а денег не приносит. Прибыль с учётом выкупа показывает, сколько в среднем остаётся с одной продажи, если разложить на неё эти потери. Это самая честная цифра юнит-экономики товара.

Нужно ли давать доступ к кабинету

Нет. Достаточно скачать отчёт о начислениях в разделе «Финансы» и перетащить его на эту страницу. Если хотите, чтобы данные обновлялись сами, кабинет можно подключить ключом Ozon API с правами только на чтение.

Как считается: «Ozon перечислит» — сумма всех строк отчёта. Налог считается по выбранной системе: от цены продажи или, для УСН «Доходы минус расходы», от разницы доходов и расходов. Себестоимость вычитается только у выкупленных заказов. Невыкуп — заказ с обратной логистикой без продажи; «в пути» — заказ, по которому пока списан только эквайринг или доставка.

Неофициальный инструмент, не связан с Ozon. Расчёт ориентировочный и не заменяет бухгалтерию.
