Прибыль на Ozon

Перетащите отчёт о начислениях из кабинета продавца и сразу увидите чистую прибыль по каждому товару: после комиссии, логистики, невыкупов, налога и себестоимости. Файл обрабатывается в вашем браузере и никуда не отправляется.

Перетащите сюда файлы из кабинета Отчёт о начислениях, а для себестоимости — файл «Товары и цены». Можно несколько отчётов за разные месяцы. Выбрать файл

Где взять отчёт

  1. В кабинете продавца откройте Финансы → Начисления → Детализация начислений.
  2. Нажмите Скачать отчёт, выберите По начислениям и период.
  3. Для себестоимости откройте Цены и нажмите Скачать шаблон xlsx.
  4. Перетащите оба файла в поле слева.

Себестоимость подставится из файла «Товары и цены». Если её нет в кабинете, введите в таблице ниже: она запомнится в этом браузере.

Понравился расчёт? Подключите кабинет по API, и файлы больше не понадобятся

Сейчас вы скачиваете отчёт вручную. После подключения по официальному Seller API данные подтягиваются сами, а ваш дашборд открывается по личной ссылке.

  • Данные обновляются сами, без скачивания файлов.
  • Последние месяцы продаж в одном месте.
  • Себестоимость и новые товары подхватываются автоматически.
Подключить кабинет
  1. В кабинете Ozon откройте настройки и раздел с API-ключами.
  2. Создайте ключ с ролью только для чтения и скопируйте Client-Id и сам ключ.
  3. Вставьте их ниже.

Ключ «только на чтение» не даёт доступа к деньгам, реквизитам и товарам. Он хранится на сервере в зашифрованном виде, и его можно отозвать в кабинете в любой момент. Не присылайте ключ в переписке.
Нужны дополнительные показатели? Свяжитесь со мной Telegram: @@@TG_USERNAME@@

Как считается: «Ozon перечислит» — сумма всех строк отчёта. Налог берётся от цены продажи (реализации). Себестоимость вычитается только у выкупленных заказов. Невыкуп — заказ с обратной логистикой без продажи; «в пути» — заказ, по которому пока списан только эквайринг или доставка.

Неофициальный инструмент, не связан с Ozon. Расчёт ориентировочный и не заменяет бухгалтерию.
