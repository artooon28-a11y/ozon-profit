1. О сервисе

seller-profit.online (далее — сервис) помогает продавцам Ozon посчитать чистую прибыль по товарам из отчёта о начислениях или по данным, полученным через официальный Ozon Seller API. Владелец сервиса — Максимов Антон Сергеевич, самозанятый, ИНН 433100539271, e-mail htkirov@yandex.ru.

Пользуясь сервисом, вы соглашаетесь с этими условиями. Сервис бесплатный.

2. Сервис не связан с Ozon

Это неофициальный инструмент. Ozon не является стороной соглашения и не отвечает за работу сервиса. Названия Ozon и Ozon Seller упоминаются только для описания, с какими данными работает сервис.

3. Расчёт ориентировочный

  • Цифры считаются по данным Ozon и введённой вами себестоимости. Ozon сам предупреждает, что данные API могут не совпадать с личным кабинетом.
  • Налог и НДС считаются упрощённо, по выбранной вами ставке, и не учитывают всех особенностей вашего налогового режима.
  • Расчёт не является бухгалтерской, налоговой или финансовой консультацией. Перед важными решениями сверяйте цифры с кабинетом Ozon и с бухгалтером.

4. Ваш API-ключ и личная ссылка

  • Подключайте только ключ с ролью Admin read only (только чтение). Вы отвечаете за то, какой ключ передаёте сервису.
  • Личная ссылка на дашборд (seller-profit.online/d/…) даёт доступ к вашим данным. Храните её как пароль и не пересылайте. Если ссылка попала к другим людям, нажмите «Отключить» или удалите ключ в кабинете Ozon.
  • Подключайте только свой кабинет или кабинет, на подключение которого у вас есть право.
