3. Зачем

  • Посчитать чистую прибыль по вашим товарам и показать её на дашборде.
  • Обновлять дашборд автоматически, пока кабинет подключён.
  • Защищать сервис от злоупотреблений (ограничение частоты подключений).

Данные не используются для рекламы, не продаются и не передаются третьим лицам для их собственных целей.

4. Правовое основание

Ваше согласие на обработку персональных данных (п. 1 ч. 1 ст. 6 152-ФЗ), которое вы даёте отдельно, отмечая галочку перед подключением кабинета. Текст согласия: seller-profit.online/consent. В режиме загрузки файла данные на сервер не поступают, поэтому согласие не требуется.

5. Что мы делаем с данными

Сбор, запись, хранение, использование для расчёта, обновление, удаление и уничтожение. Обработка автоматизированная.

API-ключ используется только для запросов к официальному Ozon Seller API (api-seller.ozon.ru) с правами только на чтение. Ключ передаётся только в Ozon — той же компании, которая его выдала.

6. Где хранятся данные и кто имеет к ним доступ

  • Сервер расположен в России, в облаке Рег.облако (Москва). Провайдер предоставляет оборудование и не имеет доступа к содержимому: API-ключи и данные кабинета хранятся зашифрованными, ключ шифрования есть только у оператора.
  • Трансграничная передача персональных данных не осуществляется: сайт не подключает внешние шрифты, счётчики, рекламу и аналитику.
  • Доступ к серверу есть только у оператора.

7. Как долго хранятся

  • Данные подключения (Client-Id, API-ключ, данные кабинета) — пока кабинет подключён. Данные кабинета обновляются при открытии дашборда, если с прошлой загрузки прошло больше 6 часов.
  • После нажатия «Отключить» на дашборде или по вашему письму оператору данные удаляются с сервера сразу и без возможности восстановления. Резервные копии базы данных не делаются и не хранятся.
  • Данные в браузере (режим файла, себестоимость, настройки) хранятся на вашем устройстве, пока вы их не очистите в настройках браузера.

8. Как защищены

  • Соединение только по HTTPS.
  • API-ключ и данные кабинета зашифрованы (Fernet: AES-128 + HMAC-SHA256).
  • Дашборд открывается по личной ссылке со случайным кодом; на сервере хранится только хэш этого кода.
  • Сервис просит ключ с ролью Admin read only: таким ключом нельзя изменить цены, товары или заказы.
  • Журналы сервера не содержат адресов страниц и IP-адресов посетителей.

9. Cookie и хранилище браузера

Сайт не устанавливает cookie и не использует счётчики посещений. В памяти браузера (localStorage) на вашем устройстве сохраняются себестоимость товаров и выбранные настройки налога и периода — только для вашего удобства, на сервер они не отправляются.

Оператор может обновлять политику. Новая редакция публикуется на этой странице с датой. Если изменения расширяют состав или цели обработки, сервис попросит согласие заново.
